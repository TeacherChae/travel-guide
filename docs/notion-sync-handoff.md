# Notion 재개 지침 — 청년 Carte Blanche Duo / PMP 미구매

**작성: 2026-09-09 · 현재 상태: Notion 미반영(인증 차단).**

이 문서는 SSH 세션에서 Notion이 `Auth required`를 반환한 뒤, 레포에 먼저 반영한 내용을 다음 데스크탑 세션에서 적용하기 위한 작업 지침입니다. 이번 작업에서 일자·준비·예약 DB에 저장된 변경은 없습니다. 이전에 만든 입장권 비교 페이지는 존재하지만 새 구매 방침과 준비 DB를 자동으로 반영하지 않습니다.

## 다음 세션에 그대로 전달할 요청

> `docs/notion-sync-handoff.md`와 `docs/predeparture-checklist.md`를 읽고, 데스크탑에서 Notion 인증 상태를 확인한 뒤 최신 원격 내용을 다시 조회해 반영해줘. 순서는 **월·화 일자 DB 수정 → 준비 DB 정리 → 연결된 예약/장소와 대시보드 예산 대조**야. 청년 Carte Blanche Duo 1년 사용, PMP는 사지 않아. 아직 구매하지 않은 것을 완료로 표시하지 말고 기존 실제 구매 기록은 보존해. 마지막에는 수정한 페이지들을 다시 읽어 검증해줘.

## 0. 인증·조회부터

1. 필요하면 데스크탑의 정상 브라우저를 사용할 수 있는 터미널에서 `codex mcp login notion`을 실행한다. SSH 세션에서 실패한 OAuth를 토큰 복사나 임의 자격증명 검색으로 우회하지 않는다.
2. 새 작업 세션에서 대상 대시보드와 아래 데이터 소스의 **최신 스키마·행**을 fetch/query한다. 로컬 과거 백업을 현재 원격 상태로 간주하지 않는다.
3. 원격 변경 전 백업은 `.omx/` 아래 비공개 작업 파일로 저장하고 커밋하지 않는다. 스키마의 실제 제목 필드·선택값·relation을 확인한다.
4. 도구가 quota/auth 오류를 반환하면 같은 호출을 반복하지 않는다. 인증/권한이 풀리지 않았다면 미반영 상태를 명확히 보고한다.

`날짜`는 한국에서 준비할 권장 마감일이며 실제 방문일과 구분한다. 미술관 방문일은 연결된 예약 DB의 `대상일`/관련 일자에 둔다. 명확한 결제/발급 증거가 없는 새 구매는 `시작 전`으로 생성한다.

### 회원권과 방문비의 중복 방지

- `index.html#daily-budget-data`가 현재 예산 원본. `admission_plan=carte-blanche-jeunes-duo`.
- 회원권 항목 `carte-blanche-jeunes-duo`는 p2에 **€40 한 번**, `purchase_status=planned`. 한국에서 구매할 예정 비용을 첫 사용일에 배정한 것이지 이미 결제했다는 뜻이 아니다.
- 오랑주리·오르세는 각각 추가 **€0**(회원카드·동반 조건부). 무료 미술관으로 표기하지 않는다. 로댕은 별도 현장권 €28/2인.
- 마르모탕은 온라인 €29/2인, 모네는 결제 확인서 총€27의 **잠정 주문 배정액**, MDIG는 할인 확정 전 €24/2인 기본 포함.
- 원장의 선택 항목·2인 cents·range로 일일 합계를 재계산한다. 이번 레포 기본 합계는 **€1,652.30**, 도착 택시 선택 시 **€1,689.30**. 기본 RER 선택은 비용 비교 기준일 뿐 9/12 공사일 정상 직결 운행을 뜻하지 않는다.
- 일일 기본액: 토9/12 **€110.00**, 일 **€262.30**, 월 **€233.10**, 화 **€195.10**, 수 **€283.20**, 목 **€213.10**, 금 **€201.30**, 토9/19 **€154.20**.
- 위 금액은 항공·숙박 등을 제외한 활동 예산이지 앞으로 결제할 잔액이 아니다. 기존 구매분도 방문 비용으로 포함한다.

연결된 예약 DB에서 기존 PMP 행 `3d5ea411129f811bacc2c26765100bb8`, 오랑주리 `3d5ea411129f8166b917f8739c807b3b`, 오르세 `3d5ea411129f81e1a7c3e8d867f4d8d6`를 새 방침과 대조한다. 새 회원권 기록을 만들면 두 날짜·시설에 연결하되 한 결제로 유지한다. 명확한 기존 결제 기록은 삭제하지 않는다.

모네 예약 행 `3d5ea411129f815791e3e0bdfd0ccdd7`에는 과거 €24와 구매 완료 기록, 레포 과거 예산에는 €26이 있었다. `ticket.pdf`는 €27 결제 확인서지만 상품·수량·입장 시각은 없다. **원래 구매 완료 상태는 유지하고 실명세 확인 전 과거 결제 숫자를 임의로 덮어쓰지 않는다.** 잠정 예산27과 실제 결제 명세 확인 과업을 구분한다. 카드 일부 번호·주문/승인/거래 번호·QR은 Notion이나 이 문서에 복사하지 않는다.

월·화 이후 일요일 회원권/마르모탕, 수요일 MDIG·기존 모네 비용도 최신 원장과 맞추고 대시보드의 9/8 옛 합계·‘개별권 기준’ 문구를 새 기준으로 갱신한다. 기존 입장권 비교 페이지에는 선택 확정 배너와 현재 준비 목록을 연결하되 과거 비교표의 범위·전제는 보존한다.
