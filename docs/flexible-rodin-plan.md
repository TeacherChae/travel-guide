# 최종 일정 — 로댕만 유연하게 선택

**기준일: 2026-09-09 · 여행자용 현재 결정 문서.** 지베르니에 가기 전에 오랑주리·마르모탕 모네·오르세를 보고, 화요일은 두 미술관만 방문한다. 로댕은 일요일에 짧게 시도하거나 금요일에 대체하며 **한 번만** 간다. 실제 예약·구매는 이 문서가 대신하지 않는다.

시각은 예약 목표다. 예약 완료·입장 보장·실시간 이동시간을 뜻하지 않는다.

## 일요일 운영

- **07:00–08:30:** 숙소에서 예배를 시청한다.
- **10:00:** 노트르담 미사. `11:15경`은 종료 예상치이므로 성당 전체 관광 시간과 구분한다.
- **12:00 목표:** 생트샤펠 관람. 아직 예약하지 않았고 보안검색 시간을 별도로 둔다.
- **관람 후:** 라탱 지구에서 간단히 점심을 먹고 Fête로 간다.
- **오후:** Fête의 일요일 공식 운영은 10:00–18:00이다. 18시까지 머물 의무는 없으며, 퍼레이드는 공식 안내에 14:00/14:30이 함께 표시되므로 우선 관람 시 Panthéon 13:30–13:45 도착을 목표로 한다. 늦어지면 Village에 합류하고 일정을 무리하게 만회하지 않는다.
- **16시경에 실제로 나올 수 있고 체력이 괜찮을 때만:** 로댕 16:40–18:15 핵심 관람을 시도한다. 입장 지연·대기 발생 시 금요일로 넘긴다.
- **21:00 목표:** MyRealTrip에서 구매한 바토 파리지앵 티켓을 사용한다. 바우처의 날짜·출발편·승선장·21:00 조건을 확인한다.

Fête 일반 입장·공연은 무료이며 음식·음료·상품·유료 체험은 별도다. 무료 등록은 혼잡에 대비한 권장 준비지만 직접 해야 한다. [Village](https://lafetedeparis.fr/le-village/) · [일요일 프로그램](https://lafetedeparis.fr/programmation-2026/) · [파리 6구 안내](https://mairie06.paris.fr/pages/fete-de-paris-2026-defile-costume-et-guinguette-35905) · [무료 등록](https://www.helloasso.com/associations/paris-genevieve/evenements/la-fete-de-paris-2026)

## 로댕 선택 규칙

화요일은 마르모탕과 오르세에 집중한다. 일요일에 Fête를 충분히 즐기면 로댕을 생략하고, 금요일 **14:00–16:00**을 fallback으로 사용한다. 일요일에 로댕을 봤다면 금요일에는 **몽소 14:00–15:10 → 약 20분 이동 → Pleincœur 15:30–16:00**을 선택 후보로 둔다. 로댕 단독권 €28/2인은 두 날짜 중 한 번만 계산한다. Carte Blanche는 로댕 일반 입장을 포함하지 않는다. [로댕 공식 방문·요금](https://www.musee-rodin.fr/preparer-sa-visite/informations-pratiques)

진화 대전시실·파리 식물원은 월요일 오후에 포함한다. 달리그르·쿨레 베르트와 Le Florentin만 보류 후보다. 사마리텐도 핵심 일정이 아니다. 추가할 때만 예약·시간·예산을 다시 계산한다.

## 2인 예산

유로는 2인 계획 예산이며 항공·숙박·도시세·개인 쇼핑은 제외한다. 공개 원장은 [`index.html#daily-budget-data`](../index.html#daily-budget-data)이고, 원화 결제액은 환율 없이 별도 표시한다. 메뉴·운임·잔여석 미확인 값은 추정이다.

월요일 교통비는 **€2.55 × 3회 × 2인 = €15.30**, 진화 대전시실 일반권은 **€13 × 2인 = €26**으로 반영했다. [IDFM 운임](https://www.iledefrance-mobilites.fr/titres-et-tarifs/detail/ticket-metro-train-rer) · [MNHN 요금](https://www.mnhn.fr/en/grande-galerie-de-l-evolution-gallery-of-evolution) (확인 2026-09-09).

## 예약 우선순위

1. Carte Blanche Jeunes Duo 1년 €40을 구매할 경우 명의자 연령·사진·증빙·디지털 카드·게스트 동행을 확인한다. 오랑주리와 오르세는 유효한 카드 조건의 일반 관람 계획이다.
2. 생트샤펠 9/13 12:00, 마르모탕 9/15 10:00, 루브르 9/17 09:00의 실제 표를 확인한다. 들라크루아는 루브르 표의 연계 조건을 확인하고 중복 구매하지 않는다.
3. 모네의 집 영수증은 실제 e-ticket·방문일·QR로 대조한다. SNCF와 SNGO 연결도 함께 확인한다.
4. 크루즈는 결제 완료 기록이 있지만 바우처와 승선 조건을 확인한다. Fête 무료 등록·식당·호텔 짐 보관은 별도 과업이다.
