# 출국 전 준비 체크리스트

**기준일: 2026-09-09 · 여행: 9/12–19 · 2인 · 시각은 파리 현지.** `[미완료]`는 완료 증빙 없음, `[구매기록]`은 기존 구매 후 실제 표·설치 등 후속 확인이 남음, `[당일확인]`은 현장 상태를 봐야 한다는 뜻이다. 계획 시각만으로 예약 완료 처리하지 않는다.

현재 전략은 **PMP 없이 Carte Blanche Jeunes Duo 1년 €40을 구매·발급해 사용하는 것**이다. 아직 회원카드가 없으므로 오랑주리(월 9/14)와 오르세(화 9/15)는 조건부 계획이다. 바토 파리지앵은 MyRealTrip 2인 총 **₩27,052 결제 완료**이며, 원화는 유로로 환산하지 않는다. 최종 일정은 [로댕 유연 운영안](flexible-rodin-plan.md)을 따른다.

- **[당일확인]** 9/18 체크아웃 후 짐을 Pullman에 맡기고, 9/19 쇼핑 뒤 반드시 짐을 회수한다. CDG 20:35 항공편의 항공사 마감·터미널·공항 이동을 먼저 확인한다.

- **[당일확인]** 버터·식품을 한국으로 가져갈 때 품목별 신고·검역을 확인한다. 일반적인 허용량을 이 문서에서 단정하지 않는다. [한국 관세청 여행자 통관](https://www.customs.go.kr/english/cm/cntnts/cntntsView.do?cntntsId=2715&mi=8027)
- **[미완료]** 여권, 예약번호, QR, 호텔 주소, 보험·카드 분실 연락처를 각자 휴대폰과 종이에 보관한다. 체크리스트를 표시해도 실제 예약·결제는 실행되지 않는다.

체크박스는 실행 기록일 뿐 실제 예약·결제를 수행하지 않는다. 실제 완료는 각 행의 증거로 판단한다.
