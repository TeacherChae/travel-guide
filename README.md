## 2. 일정을 짠 원칙

### 요일별 휴관이 순서를 지배한다

| 요일 | 닫는 곳 |
|---|---|
| 월 | 오르세 · 피카소 · 로댕 · 마르모탕 · 아랍세계연구소 · **카르티에 재단** |
| 화 | 루브르 · 오랑주리 |

월요일은 루브르, 화요일은 오르세. 마르모탕(월 휴관)과 오랑주리(화 휴관)는 일요일에 묶는다.

카르티에 재단은 팔레 루아얄 이전 뒤 **월요일 휴관**이라 표에 추가했다. 일정에서는 제외돼 있어 당장 영향은 없다.

### 숙소 위치가 동선을 결정한다

5구 숙소가 도보권을 크게 넓혀준다.

- 노트르담 10분 / 마레·보주 광장 18분 / 마르셰 몽주 7분
- 아랍세계연구소는 바로 옆 건물
- **오스테를리츠역 도보 10분** — RER C 직통
- 오르세역 → 샹드마르스 RER C 2정거장 5분 (9/13 크루즈 동선의 근거)

### 확정된 제약

- **베르사유는 가지 않기로 함.** 원래 9/16에 있었으나 제외.
- **지베르니는 9/16 수요일로 이미 예약 완료.**
- **9/13 일요일 아침 07:00–08:30에는 숙소에서 한국 교회 오후 2시 예배 라이브 스트리밍을 드린다.** 한국과 파리의 9월 시차는 7시간이다.
- **9/13 오랑주리 13:00 → 마르모탕 15:30**, **9/15 오르세 10:00 → 샹드마르스**로 배치. 시간은 예약 목표이며 완료를 의미하지 않는다.
- 라 로슈·팔레 루아얄·카르티에·라파예트는 이번 일정에서 제외.
- **9/17은 생트샤펠 → 달리그르 노천시장·점심 → 쿨레 베르트 → 진화과학박물관 → 파리 식물원.** 몽소 공원은 9/18로 이동.
- **9/18 11:00 기존 숙소 체크아웃 → 풀만 짐 보관 → 점심 → 몽소 → 풀만 체크인·휴식.** 사전 짐 보관 가능 여부와 비용은 호텔 확인 필요.
- **오페라 가르니에 내부 관람은 제외.**
- **몽마르트르는 제외.** 풀만(15구)에서 사크레쾨르(18구)를 왕복하면 마지막 날에 파리를 가로지르게 된다.
- **9/19는 르봉 마르셰로 확정.** 케 브랑리를 넣었다가 뺐다. 마지막 날은 관람보다 선물 쇼핑이 실용적이고, 백화점에 détaxe 창구가 있어 서류를 받아 CDG PABLO에서 승인만 받으면 된다.
- **카르티에 재단은 사실상 제외.** 9/14(월)에 걸려 있으나 월요일 휴관이다. 갈 계획이 없으므로 휴관 표에만 남기고 일정은 손대지 않았다.
- 퐁피두는 2025.9.22부터 2030년까지 폐관. 일정에서 제외됨.
- 9/19가 유럽 문화유산의 날과 겹칠 가능성. 시내 혼잡 예상.

### 하루 구성 규칙

- 하루 2~3곳, 9~10시 출발 (본인 선호)
- **모든 날은 숙소에서 시작해 숙소에서 끝난다.** 앞뒤 이동 구간이 반드시 붙어 있어야 한다.
- 9/19는 르봉 마르셰·라 그랑드 에피스리 쇼핑 후 **풀만에 들러 짐을 회수**한 뒤 공항으로 간다. 이 경유가 빠지면 짐을 못 찾는다.

- 이미 구매한 표도 방문일 총비용에 포함하며 **오늘 추가로 결제할 금액**은 아님. 패스를 사용할 경우 원장의 개별권 대신 해당 비용을 조정해야 하며 패스 가격을 그냥 더하지 않음.
- 제외: 항공·숙박·도시세·미확인 짐 보관료·의류/명품 등 개인 쇼핑·팁·환전/카드 수수료·새 교통카드 구매비. 호환 스마트폰 또는 기존 카드 기준.
- 추정 범위는 주문·교통 선택에 따른 계획 범위이며 통계적 신뢰구간·견적·가격 상한이 아님. 선택 상태는 새로고침하면 초기화.

### 공항 ↔ 숙소

CDG ↔ 파리 시내 택시는 **정액제**다. 세느강 기준으로 갈리는데 **우안 €56 / 좌안 €65**이고, **5구 아파트와 15구 풀만 둘 다 좌안이라 €65**다. 24시간 동일하고 짐과 4인까지 포함이며, 중간에 들르면 정액이 깨진다.

RER B 2인 €28과 승강장 택시 €65의 차이는 €37이다. 18:30은 항공편 도착 예정 시각이며 공항을 나오는 시각은 입국심사·수하물 상황에 따라 달라진다. RER B는 Saint-Michel–Notre-Dame 하차 후 숙소까지 걸어가는 기준이고, 택시는 숙소 문 앞까지 가는 대안이다. 실제 도착 터미널과 당일 운행·교통 상황은 별도 확인한다.

**우버는 택시와 다른 업종(VTC)이라 정액제가 없다.** 평시 €45–70이지만 피크에는 €100을 넘고, CDG에서는 지정 VTC 승차장까지 걸어가야 한다. 택시 승강장은 나오면 바로다.

택시를 쓸 때 두 가지를 주의한다. **호객은 전부 무면허다** — 정식 기사는 호객이 금지돼 있고, 승강장은 건물 밖 표지판 아래에 있다. 무면허는 같은 구간을 €120–200에 받는다. 그리고 **결제 단말기 금액을 눈으로 확인하고 누른다** — 2026년 상반기에 화면 조작으로 금액을 바꾸는 수법이 적발됐고(피해 80명·68만 유로) 주 무대가 에펠탑과 몽파르나스 일대라 9/18–19 풀만 근처가 여기 해당한다. 우버는 앱 결제라 이 수법에는 노출되지 않는다.

### 교통 결제 (2025년에 바뀜)

**파리 메트로 개찰구는 해외 신용카드 직접 태그가 안 된다.** 2025년 11월 5일 종이 티켓 판매가 종료됐고, 컨택리스는 버스에만 단계적으로 열리는 중이다. Apple Wallet의 Navigo(관광객도 등록 가능)나 현지 자판기의 Navigo Easy 카드(€2)가 필요하다. 공항 구간은 별도 티켓(€14/인)이며 이것도 Navigo에 충전한다.

## 7. HTML 구조

### 기본 방침

- **단일 파일.** 외부 CSS·JS·폰트 없음. 빌드 과정 없음.
- **모바일 우선.** 최대 폭 720px.
- 폰트는 시스템 스택만 사용 (`-apple-system` → `Apple SD Gothic Neo` → `Pretendard` → `Noto Sans KR`).
- 외부 요청은 구글 지도 iframe과 장소 상세 카드의 Wikimedia Commons 사진이다. 사진이 실패해도 설명 카드는 대체 화면으로 정상 표시된다.

### 레이아웃

```
header.top          — 제목 + 메타 칩
.tabbar             — 상단 고정, 12개 탭 (8일 + My Maps + Museum Pass + 비용 + 정보)
section.panel × 12  — id="p1".."p8", "pm"(My Maps), "ppass"(Museum Pass), "pc"(비용), "pi"(정보)
  .panel-head       — 그날 제목
  .day-itinerary    — 지도·일정 묶음 (sticky 경계: 예산을 가리지 않음)
  .mapbox           — 구글 지도 iframe (일정 안에서만 sticky, top:53px)
    iframe          — 기본값은 그날 전체 경로
    .mapbar         — 캡션 + "이 날 전체" 리셋 버튼
  button.stop       — 장소 카드 (탭하면 사진 상세 카드)
  button.leg        — 장소 사이 얇은 경로 바
  .note             — 주의사항
  aside.daily-budget — 2인 일일 합계·분류별 금액·장소별 산정 근거
dialog.place-dialog — 장소 사진·설명·배지·지도 버튼
```

### 지도 동작 (핵심)

**장소·경로 선택은 페이지 안에서 바뀌고, 필요하면 현재 지도를 Google Maps로 이어서 연다.**

- `button.stop`을 누르면 장소 사진과 기존 설명이 담긴 모달 카드가 열린다.
- 상세 카드의 "지도에서 보기" 또는 `button.leg`를 누르면 해당 패널의 iframe `src`를 교체하고, `.is-active` 클래스로 선택 상태를 표시한다.
- 같은 경로 항목을 다시 누르거나 "이 날 전체"를 누르면 기본 경로로 복귀(첫날은 아래 별도 규칙).
- **첫날 RER B / 택시 탭:** 기본 RER B. 탭 선택으로 CDG→실제 숙소의 iframe·캡션·외부 Maps 링크·공항 카드 상세 지도·2인 예산을 함께 변경한다. 좌우 화살표/Home/End 지원.
- 첫날 "선택 경로"는 선택한 공항 교통수단으로 복귀, "이 날 전체"는 공항→숙소→마트→저녁→산책→숙소의 개략 동선. 전체 보기나 도보 구간 확인은 예산의 공항 교통 선택을 바꾸지 않는다.
- RER B 설명은 Saint-Michel–Notre-Dame 하차 후 도보 기준. Google 임베드가 특정 노선을 강제하지 못하므로 지도에 다른 대중교통 대안이 나올 수 있으며, 택시는 일반 차량 경로이지 택시 전용 차로·예약 서비스가 아니다.
- "Google Maps에서 열기"는 현재 iframe에 표시된 장소나 경로를 공식 Maps URL 형식으로 변환해 새 탭이나 Google Maps 앱에서 연다. API 키는 필요 없다.
- 지도가 화면 밖이면 부드럽게 스크롤해 올려준다.
- `My Maps` 탭은 공개된 Google My Maps 임베드를 별도로 표시한다. 날짜별 경로 지도와 달리 My Maps의 레이어 전환은 임베드 안에서 처리한다.

임베드 URL 형식:

```
장소: https://maps.google.com/maps?q={lat},{lng}&z=16&hl=ko&output=embed
경로: https://maps.google.com/maps?saddr={A}&daddr={B}&dirflg={w|r}&hl=ko&output=embed
```

`dirflg=w`는 도보, `r`은 대중교통, `d`는 차량(외부 Maps URL의 `travelmode=driving`으로 변환). 여러 경유지는 `daddr=A+to:B+to:C`.

**이 방식은 API 키가 없는 구식 임베드다.** 구글이 언제든 막을 수 있으므로, 깨지면 Maps Embed API(키 필요)로 교체해야 한다.

### 장소 상세 카드

- 장소명별 Wikimedia Commons 파일명은 `placePhotos` 객체에 모아뒀다.
- 이미지는 카드를 처음 열 때만 로드하고, 각 카드 하단의 출처 링크에서 원본과 라이선스를 확인할 수 있다.
- 이미지 로드 실패 시 사진 영역만 대체 화면으로 바뀌며 설명·비용·예약 정보와 지도 버튼은 그대로 작동한다.
- 현재 일정에 들어간 장소와 저장 스팟의 이름이 다를 수 있다. 장소 카드를 열면 저장 스팟과 별개로 일정 설명·경로가 표시된다.

### 배지 규칙

| 클래스 | 용도 | 색 |
|---|---|---|
| `b-free` | 무료 | 초록 |
| `b-cost` | 금액 | 인디고 |
| `b-book` | 예약 필수 | 빨강 |
| `b-note` | 그 외 참고 | 회색 |

경로 바의 `.leg-cost`에 `free` 클래스를 붙이면 초록으로 바뀐다. 지하철 구간은 "나비고 / €2.55"처럼 병기해 데이패스 구매 여부에 따라 읽히게 했다.

### 저장 없음

정보 탭 체크리스트, 첫날 공항 교통수단, 예산의 선택 체크박스는 세션 한정이다. 새로고침하면 초기화된다. localStorage를 쓰지 않았다.

## 2인 예산 구현·검증 (2026-09-08)

- **단일 원장:** `index.html`의 `<script type="application/json" id="daily-budget-data">`. 외부 fetch나 빌드 없이 `file://`로도 동작한다. 별도 JSON 복사본을 유지하지 않는다.
- `days.p1`–`days.p8`의 항목은 `cents`(이미 **2인 합계**, 유로 센트 정수), `range`(하한/상한 센트), `category`, `basis`, `status`, `sources`를 사용한다. `verified`는 공개 단가 확인이지 예약/실결제 확인을 뜻하지 않음.
- `place`는 같은 패널의 `.stop[data-label]` 또는 `[data-dining]` 이름과 정확히 대응한다. 장소 배지, 일일 합계, 비용 탭 합계를 같은 원장에서 렌더링한다. 이름을 바꾸면 원장도 함께 변경할 것.
- `optional` 항목은 `included`로 초기 포함 여부를 지정한다. 첫날 `arrival` 항목의 `taxi_cents`는 RER 비용에 더하는 금액이 아니라 **대체 금액**이다.
- 첫날 지도는 `p1.dataset.arrivalMode`와 `arrivalmodechange` 이벤트로 예산과 연동된다. 선택값은 `rer` / `taxi`.
- 각 날짜 `.day-itinerary`는 sticky 지도의 경계를 끝낸 뒤 `.daily-budget`을 노출한다. 이 wrapper를 제거하면 모바일에서 예산이 지도 뒤에 가려질 수 있다.
- 원장 단가 변경 시 이 문서의 기본 합계 표와 `tests/test_daily_budget.py`의 기대 합계를 함께 갱신한다. 요금·식당 정보는 테스트 성공이 아니라 공식 원문·적용 조건으로 따로 검증할 것.
