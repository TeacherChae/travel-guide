## 2. 일정을 짠 원칙

### 요일별 휴관이 순서를 지배한다

| 요일 | 닫는 곳 |
|---|---|
| 월 | 오르세 · 피카소 · 로댕 · 마르모탕 · 아랍세계연구소 |
| 화 | 루브르 · 오랑주리 |

9/14가 월요일, 9/15가 화요일이라 **월요일을 루브르로, 화요일을 마레·피카소로** 잡으면 휴관을 전부 피한다. 순서를 바꿀 때 이 표를 먼저 봐야 한다.

### 숙소 위치가 동선을 결정한다

5구 숙소가 도보권을 크게 넓혀준다.

- 노트르담 10분 / 마레·보주 광장 18분 / 마르셰 몽주 7분
- 아랍세계연구소는 바로 옆 건물
- **오스테를리츠역 도보 10분** — RER C 직통
- 오르세역 → 샹드마르스 RER C 2정거장 5분 (9/13 크루즈 동선의 근거)

### 확정된 제약

- **베르사유는 가지 않기로 함.** 원래 9/16에 있었으나 제외.
- **지베르니는 9/16 수요일로 이미 예약 완료.**
- **9/17 목요일은 비어 있음.** 베르사유를 뺀 자리. 세 가지 선택지만 제시한 상태.
- 퐁피두는 2025.9.22부터 2030년까지 폐관. 일정에서 제외됨.
- 9/19가 유럽 문화유산의 날과 겹칠 가능성. 시내 혼잡 예상.

### 하루 구성 규칙

- 하루 2~3곳, 9~10시 출발 (본인 선호)
- **모든 날은 숙소에서 시작해 숙소에서 끝난다.** 앞뒤 이동 구간이 반드시 붙어 있어야 한다.
- 9/19는 몽마르트르 후 **풀만에 들러 짐을 회수**한 뒤 공항으로 간다. 이 경유가 빠지면 짐을 못 찾는다.

## 6. 실무 메모

- **지베르니는 열차보다 셔틀 시각표를 먼저 봐야 한다.** SNGO 셔틀이 하루 몇 편뿐이고 오전엔 역→마을, 오후엔 마을→역으로 몰려 있다. sngo.fr에서 확인하고 거기 맞는 열차를 고른다. 시각표가 8월 24일자로 개정됨.
- **eSIM은 오렌지로 구매 완료.** 테더링 가능하므로 아이패드 지참 가능.
- 파리 마트는 표기 시간보다 20~30분 일찍 정리를 시작하는 경우가 많다.
- 부가세 환급(détaxe)은 체크인 **전에** PABLO 키오스크에서. 세관이 실물을 요구할 수 있으므로 환급 대상은 부치지 말 것.
- 면세 한도 1인 800달러. 주류는 별도로 2병·2L·400달러 세 조건을 동시 충족해야 면세.
- 대한항공 국제선 일반석 위탁은 1인 1개 23kg, 3변 합 158cm (손잡이·바퀴 포함).

준비물은 별도 노션 DB에서 관리 중이다. 이 문서 범위 밖.

## 7. HTML 구조

### 기본 방침

- **단일 파일.** 외부 CSS·JS·폰트 없음. 빌드 과정 없음.
- **모바일 우선.** 최대 폭 720px.
- 폰트는 시스템 스택만 사용 (`-apple-system` → `Apple SD Gothic Neo` → `Pretendard` → `Noto Sans KR`).
- 외부 요청은 구글 지도 iframe **하나뿐**. 그 외엔 오프라인에서도 열린다.

### 레이아웃

```
header.top          — 제목 + 메타 칩
.tabbar             — 상단 고정, 날짜 10개 탭 (8일 + 비용 + 정보)
section.panel × 10  — id="p1".."p8", "pc"(비용), "pi"(정보)
  .panel-head       — 그날 제목
  .mapbox           — 구글 지도 iframe (sticky, top:53px)
    iframe          — 기본값은 그날 전체 경로
    .mapbar         — 캡션 + "이 날 전체" 리셋 버튼
  button.stop       — 장소 카드
  button.leg        — 장소 사이 얇은 경로 바
  .note             — 주의사항
```

### 지도 동작 (핵심)

**모든 지도는 페이지 안에서 바뀐다. 외부 링크로 나가지 않는다.**

- `button.stop` / `button.leg` 각각에 `data-src` 속성으로 임베드 URL이 들어 있다.
- 누르면 그 패널의 iframe `src`를 교체하고, `.is-active` 클래스로 선택 상태를 표시한다.
- 같은 항목을 다시 누르거나 "이 날 전체"를 누르면 기본 경로로 복귀.
- 지도가 화면 밖이면 부드럽게 스크롤해 올려준다.

임베드 URL 형식:

```
장소: https://maps.google.com/maps?q={lat},{lng}&z=16&hl=ko&output=embed
경로: https://maps.google.com/maps?saddr={A}&daddr={B}&dirflg={w|r}&hl=ko&output=embed
```

`dirflg=w`는 도보, `r`은 대중교통. 여러 경유지는 `daddr=A+to:B+to:C`.

**이 방식은 API 키가 없는 구식 임베드다.** 구글이 언제든 막을 수 있으므로, 깨지면 Maps Embed API(키 필요)로 교체해야 한다.

### 배지 규칙

| 클래스 | 용도 | 색 |
|---|---|---|
| `b-free` | 무료 | 초록 |
| `b-cost` | 금액 | 인디고 |
| `b-book` | 예약 필수 | 빨강 |
| `b-note` | 그 외 참고 | 회색 |

경로 바의 `.leg-cost`에 `free` 클래스를 붙이면 초록으로 바뀐다. 지하철 구간은 "나비고 / €2.55"처럼 병기해 데이패스 구매 여부에 따라 읽히게 했다.

### 저장 없음

정보 탭의 체크리스트는 세션 한정이다. 새로고침하면 초기화된다. localStorage를 쓰지 않았다.

## 8. 남은 작업

1. **9/17 목요일 확정.** 정해지면 해당 패널에 지도와 경로 바를 채워야 한다. 현재는 선택지 카드 3장뿐이라 `.mapbox`도 없다.
2. **추정 요금 검증.** 오페라 가르니에, 피카소, 로댕.
3. **비상 연락처.** 주프랑스 대사관 영사과 번호가 빈칸이다.
4. **배포.** 현재는 로컬 파일이라 iOS에서 파일 앱 미리보기로만 열린다. 깃허브 페이지 프로젝트 리포지토리(`teacherchae.github.io/paris` 형태)로 올리면 해결되지만 아직 결정 안 됨. 공개 주소이므로 숙소 주소 노출을 고려할 것.
5. **소요시간은 전부 추정치.** 현장에서는 구글 지도의 실시간 계산을 따를 것.
