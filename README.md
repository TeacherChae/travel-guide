# 파리 신혼여행 가이드

2026년 9월 12–19일 파리 일정, 장소별 지도, **2인 예산**을 모은 모바일 우선 정적 웹페이지입니다. 일정·비용은 이 레포에서, 실제 예약과 당일 길찾기는 각 공식 서비스에서 관리합니다.

**문서 기준일: 2026-09-09.** 현재 `index.html`, 내장 예산 원장, 테스트를 기준으로 정리했습니다. 예약 상태는 레포에 기록된 내용이며 예약 계정과 자동 연동하지 않습니다. 가격의 공식 확인과 소프트웨어 테스트 결과는 구분합니다.

## 현재 선택과 출국 전 준비

- **Carte Blanche Jeunes Duo 1년을 사용하고 PMP는 구매하지 않는 계획**입니다. 회원권 구매 완료를 뜻하지 않습니다. 실제 공개 가입 상품에서 Duo 수량1의 **€40**을 확인했습니다. 일반 Duo1년 €79, 청년 Duo2년 €75, 자격이 필요한 할인 €32와 구분합니다.
- [전체 일정 준비 체크리스트](docs/predeparture-checklist.md): 한국에서 미리 예약/준비할 것, 현장 결정 항목, 공식 근거와 완료 증거.
- [최종 로댕 유연 운영안](docs/flexible-rodin-plan.md): 9/13 노트르담·생트샤펠·La Fête de Paris·크루즈를 고정하고, 로댕은 일요일 16시경 이탈 시에만 시도하거나 금요일 fallback으로 한 번만 방문합니다. Notion 최종안은 2026-09-09에 **57개 페이지 읽기 검증·29개 레코드 속성 갱신·기존 루트 하위 14개 보존**까지 완료했습니다.
- [이전 Fête·목요일 검토안](docs/fete-schedule-proposal.md)과 [이전 Notion DB 반영 기록](docs/notion-db-schedule-2026-09-09.md)은 중간안으로 보존합니다. [Notion 재개 지침](docs/notion-sync-handoff.md)은 인증 실패 당시의 과거 기록이며, 어떤 문서도 자동 동기화를 의미하지 않습니다.
- **9/12–13 RER B 중앙 구간 운휴**로 기존 CDG→Saint-Michel 직결 안내는 사용할 수 없습니다. 도착일 택시 대안 또는 공식 대체 경로를 확인하세요. [RATP 공사 안내](https://www.ratp.fr/decouvrir/coulisses/modernisation-du-reseau/rer-b-travaux), 확인2026-09-09.

## 실행

`index.html`을 브라우저에서 직접 열거나, 레포 루트에서 로컬 서버를 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 서버 종료는 `Ctrl+C`입니다.

- 앱 실행에 패키지 설치·빌드·API 키가 필요하지 않습니다.
- CSS, JavaScript, 예산 JSON이 `index.html` 안에 있습니다. 예산 표시를 위해 외부 JSON을 fetch하지 않습니다.
- Google Maps/My Maps와 Wikimedia 사진에는 인터넷이 필요합니다. 완전한 오프라인 지도 앱이나 PWA는 아닙니다.
- 정적 호스팅으로 제공할 수 있습니다. 이 문서는 특정 호스팅의 배포 완료 상태를 보장하지 않습니다.

### 일정을 바꿀 때 지킬 것

- 일요일 크루즈는 기존 21:00 목표를 유지합니다. 식사 없는 일반 유람선이며 월요일 디너 크루즈로 옮기지 않습니다.
- 루브르·들라크루아는 목요일 9/17로 이동했습니다. 마르모탕·오르세는 화요일에 두 곳만 보고, 로댕은 일요일 조건부 또는 금요일 fallback 중 한 번만 방문합니다.
- 9/13 숙소 예배는 한국 14:00 방송을 파리 07:00에 시청하는 계획입니다. 미사·관람 시각과 혼동하지 않습니다.
- 모네의 집 예약 기록은 9/16입니다. 열차·셔틀·다른 미술관 예약까지 완료됐다는 뜻이 아닙니다.
- 중간 체류일은 숙소에서 출발해 숙소로 돌아옵니다. **첫날은 공항 출발, 마지막 날은 공항 도착**이라는 예외가 있습니다.
- 9/18은 큰 짐을 먼저 풀만에 맡기는 동선입니다. 사전 보관·체크인 조건을 호텔에 확인해야 합니다.
- 9/19 쇼핑 후 **풀만 짐 회수**를 생략하지 않습니다. 식품 구매는 보냉·반입 조건 확인 후 결정합니다.
- 일요일 Fête는 18시까지 체류할 의무가 없습니다. 16시경 이탈하고 체력이 남으면 로댕을 시도하며, 크루즈 21시는 바우처 확인 전까지 목표 시각입니다.
- 베르사유·몽마르트르·오페라 가르니에 내부·라 로슈·팔레 루아얄·카르티에·라파예트·케 브랑리 등은 현재 일별 동선에서 제외했습니다. 원본 저장 목록에 남아 있어도 방문 계획은 아닙니다.
- 일정을 옮기면 요일별 휴관·예약 가능 시간을 공식 사이트에서 다시 확인합니다. 도보·차량 소요시간은 계획값이지 실시간 안내가 아닙니다.

## 첫날 CDG → 숙소 지도

화면의 비용 비교 기본 선택은 **RER B**, 대안은 **택시**입니다. **9/12 도착일의 실제 권장안은 공사·짐을 고려한 공식 택시**이며, 철도 선택은 당일 대체 경로·표 적용 확인이 선행되어야 합니다. 기본 선택이 운행 가능성을 보장하지 않습니다.

[RATP 공사 공지](https://www.ratp.fr/decouvrir/coulisses/modernisation-du-reseau/rer-b-travaux)는 **9/11 22:45부터 9/13까지 Gare du Nord ↔ Denfert-Rochereau 중앙 구간 운휴**를 안내합니다. 별도로 [교통정보](https://www.ratp.fr/infos-trafic/rer-transilien/b)는 9/11–13 **매일 22:45 이후** CDG/Mitry 방면 운휴를 안내합니다. 두 공지를 섞어 공항 구간이 종일 전부 멈춘다고 쓰지 않습니다. 확인2026-09-09.

- 최대 폭 720px, 시스템 폰트, 외부 CSS/JS 의존성 없는 구조입니다.
- 첫날 기본 지도는 공항→숙소 단일 구간, 나머지 날짜는 해당 날의 개략 전체 경로입니다. 같은 이동 구간을 다시 누르면 기본 지도에 복귀합니다.
- 장소 `.stop[data-src]`를 누르면 상세가 열리고, 상세의 지도 버튼 또는 `.leg`를 누르면 지도 `src`를 바꿉니다. 월·화 식당·카페 `.card[data-dining][data-src]`는 `지도에서 보기` 버튼으로 현재 지도를 바꾸며, 이번 월·화 전체 경로에도 명시적으로 연결했습니다. 다른 날 카드는 외부 지도 링크를 사용하고 자동으로 경로에 추가되지 않습니다.
- **월·화 전체 지도는 도보 개략도**입니다. 다중 경유지 대중교통 임베드가 연결선을 표시하지 않는 것을 온라인에서 확인해 이 두 화면만 도보 개략도로 바꿨습니다. 실제 교통수단·운임은 구간 버튼과 원장을 따릅니다.
- 외부 Maps의 [경유지 지원 한도](https://developers.google.com/maps/documentation/urls/get-started)는 모바일 브라우저 최대 3개, 그 외 최대 9개이며 일부 제품에서는 무시될 수 있습니다(2026-09-09 확인). 전체 경로가 빠지면 각 구간의 지도 링크를 사용합니다.
- 레거시 임베드의 `q`는 장소, `saddr`/`daddr`는 경로입니다. `dirflg=w/r/d`를 외부 Maps URL의 `walking/transit/driving`으로 변환합니다. 여러 경유지는 `daddr=A+to:B+to:C` 형태입니다.
- 이 임베드 방식의 외부 서비스 호환성은 보장하지 않습니다. 특정 노선·방문 시각·영업 여부를 정확하게 표현하는 경로 엔진도 아닙니다.
- `.day-itinerary`를 제거하면 sticky 지도가 예산을 가릴 수 있습니다. 예산은 이 묶음 밖에 유지합니다.
- 사진은 `placePhotos`의 Wikimedia Commons 파일명으로 연결합니다. 로드 실패 시 대체 화면을 표시하지만, 그것만으로 사진 URL이 검증된 것은 아닙니다.

### 예산 원장 수정 규칙

원장은 `index.html`의 `<script type="application/json" id="daily-budget-data">` **한 곳**입니다. 현재 8일에 67개 항목이 있으며 장소 배지·일일 합계·비용 탭이 이를 공유합니다.

| 필드 | 의미 |
|---|---|
| `people`, `currency` | 인원 2, 통화 EUR |
| `admission_plan` | 선택한 청년 Carte Blanche Duo 전략 |
| `rodin_plan` | `friday` 기본 fallback 또는 `sunday` 조건부 방문. 일요일·금요일 중 한 번만 활성화 |
| `rodin_day` | 로댕 항목의 시나리오 소속(`sunday`/`friday`) |
| `standalone_cents` | 회원권으로 추가0인 오랑주리/오르세의 단독권 비교값; 합계에 더하지 않음 |
| `purchase_status`, `paid_currency`, `paid_amount`, `purchase_source` | 구매 상태와 실결제 통화·금액. 바토 파리지앵은 `paid`/`KRW`/`27052`/`MyRealTrip` 사용자 보고 기록 |
| `sources` | 출처 이름·직접 URL·`checked_on` 확인일 |
| `days.p1`–`days.p8` | 날짜, 설명, `items` 배열 |
| `id` | 전체 원장에서 중복되지 않는 항목 식별자 |
| `cents` | **이미 2인 합계인** 유로 센트 정수. 다시 2배 하지 않음 |
| `range` | 같은 2인 기준 하한·상한 센트. `하한 ≤ cents ≤ 상한` |
| `category`, `basis` | 비용 분류와 수량·단가·조건을 적은 산정 근거 |
| `status` | `verified` 공식 단가, `estimate` 추정, `free` 무료 활동, `excluded` 범위 제외, `paid` 사용자 보고 구매 완료 |
| `sources` (항목) | 상위 출처 사전의 키 목록. 원문이 증명하는 범위만 설명 |
| `place` | 같은 패널의 `.stop[data-label]` 또는 `[data-dining]` 이름과 정확히 대응 |
| `meal` | 아침·점심·저녁 식비 누락/중복 검증용 구분 |
| `optional`, `included` | 체크로 포함 여부를 바꿀 항목과 초기 선택값 |
| `taxi_cents`, `taxi_basis`, `taxi_sources` | 첫날 `arrival` 항목의 택시 대안. RER 비용을 **대체** |

`verified`는 공개 요금을 확인했다는 뜻이지 실제 예약·구매·청구액이 확인됐다는 뜻이 아닙니다. `excluded`의 €0 역시 호텔이나 쇼핑이 무료라는 뜻이 아닙니다.

첫날 모드 상태는 `p1.dataset.arrivalMode`(`rer`/`taxi`)로 유지하고 `arrivalmodechange` 이벤트로 예산을 갱신합니다. 비용은 유로 센트 정수로 합산하고, 원화 결제 완료액은 유로로 환산하지 않고 별도 누적·표시합니다.

금액·장소를 바꿀 때:

1. 공식 원문에서 적용 날짜, 인원, 단독/통합권, 일반/할인, 주문 수량을 확인합니다. 검색 요약·기존 문서만으로 확정하지 않습니다.
2. 원장의 금액·범위·근거·출처·확인일을 갱신합니다. 추정은 `estimate`로 남깁니다.
3. 장소 이름·동선이 바뀌면 카드, 원장의 `place`, 관련 CSV/배치 기록, 경로 앞뒤 연결도 대조합니다.
4. **기존 정적 가격 배지도 따로 확인합니다.** 2인 예산 배지는 자동 생성되지만 기존 1인 입장료·이동비 설명은 수동 작성입니다.
5. 원장 변경에 맞춰 이 문서의 기본 합계와 `tests/test_daily_budget.py` 기대값을 함께 갱신합니다.
6. 새 의존성·외부 데이터 로딩을 추가하지 않고 기존 단일 파일 동작을 유지합니다.

for (const [, attrs, body] of html.matchAll(/<script([^>]*)>([\s\S]*?)<\/script>/g)) {
  if (attrs.includes('application/json')) JSON.parse(body);
  else new vm.Script(body);
}
console.log('Inline JavaScript and JSON: OK');

### 브라우저 회귀 테스트

이미 설치된 Playwright와 Chromium을 재사용합니다. 브라우저 테스트용 도구이며 앱의 실행 의존성이 아닙니다.

```sh
PLAYWRIGHT_MODULE=/path/to/existing/node_modules/playwright \
CHROMIUM_PATH=/path/to/chromium \
node tests/browser_smoke.cjs
```

기본 모듈/브라우저 경로로 실행할 수 있는 환경이면 환경변수 없이 실행해도 됩니다. 이 레포에는 npm 설치·자동 브라우저 다운로드 단계가 없습니다.

검증 범위:

- RER B↔택시, 공항 상세 지도, 선택 경로/전체 경로 복귀, 외부 Maps 모드 일치.
- 키보드 전환과 상위 날짜 패널의 독립성.
- 월·화 전체 동선과 각 구간 연결, 식당 지도 전환, 들라크루아·로댕 상세, 일요일 Fête·크루즈 유지.
- PMP 비교 합계와 오르세/들라크루아/로댕 예약 조건 표기 구분.
- 8일 합계, 선택 비용의 가감, 장소 배지·비용 탭 동기화, 새로고침 초기화.
- 320/390/1280px에서 가로 넘침과 sticky 지도의 예산 가림 방지.

브라우저 테스트는 외부 요청을 차단합니다. **테스트 통과는 Google 서비스 가용성이나 가격·당일 운행의 정확성을 증명하지 않습니다.** 2026-09-09에는 실제 Google iframe으로 목요일 루브르·들라크루아, 일요일 조건부 로댕, 금요일 로댕 대안의 전체 경유 경로 렌더링을 별도 확인했습니다. 다중 경유지 전체 지도는 **도보 개략도**이며 실제 이동 수단은 각 구간 버튼으로 확인합니다. 대중교통 모드의 경유지 제약 때문에 전체 경로를 대중교통으로 표시하지 않습니다. [Google 공식 경유지 안내](https://developers.google.com/maps/documentation/directions/get-directions#waypoints) · 확인2026-09-09. 이는 방문일 실시간 길찾기·교통 운행 검증과 다릅니다.

현재 검증 기준은 Python 테스트 **33개**, 브라우저 회귀, 인라인 문법/JSON 검사입니다. 별도 lint·TypeScript 설정·CI 워크플로는 없습니다. 실제 방문일 영업·예매 잔여석·실결제액은 검증 범위 밖입니다.
