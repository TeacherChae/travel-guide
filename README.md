# 파리 신혼여행 가이드

2026년 9월 12–19일 파리 여행을 위한 모바일 우선 정적 가이드입니다. 장소·동선·2인 예산·Google Maps 임베드를 한 페이지에서 보고, 실제 예약과 당일 운행은 공식 서비스에서 확인합니다.

**문서 기준일: 2026-09-09 · 현지 시각 기준.** 이 저장소는 예약 시스템이 아니며 계정·결제·실시간 재고와 연동하지 않습니다.

- [출국 전 준비 체크리스트](docs/predeparture-checklist.md) — 예약·티켓·교통·숙소·짐·결제·세관 확인

### 현재 결정

- **Carte Blanche Jeunes Duo 1년 €40을 사용할 계획**이며 아직 구매·발급 완료가 아닙니다. PMP는 구매하지 않습니다.
- 9/13 바토 파리지앵 2인 티켓은 **MyRealTrip에서 총 ₩27,052 결제 완료**로 기록했습니다. 원화는 유로 예산으로 환산하지 않습니다.
- 9/13은 숙소 예배 → 노트르담 미사 → 생트샤펠 → 간단한 점심 → La Fête de Paris → 크루즈 순서입니다. 축제에서 일찍 나오고 체력이 괜찮을 때만 로댕을 짧게 봅니다.
- 로댕은 일요일 조건부 방문 또는 금요일 fallback 중 한 번만 계산합니다. 화요일은 마르모탕·오르세 두 곳만 봅니다.

## 실행

패키지 설치 없이 `index.html`을 직접 열거나 로컬 서버를 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 <http://127.0.0.1:8000>을 엽니다.

- CSS·JavaScript·예산 원장은 `index.html` 하나에 들어 있습니다.
- Google Maps/My Maps와 사진은 인터넷이 필요합니다. 예약·결제 기능은 없습니다.
- 정적 호스팅은 가능하지만 특정 호스팅에 배포된 상태를 보장하지 않습니다.

| 날짜 탭 | 9/12–9/19 일정·장소·구간·일일 예산 |
| 첫날 RER B / 택시 | 공항 경로와 첫날 예산을 함께 전환 |

선택 상태는 새로고침하면 초기화됩니다. 지도는 실시간 운행·예약 잔여석·특정 노선을 보장하지 않습니다.

### 일정상 주의

- Fête는 일요일 오후 체류 시간을 고정하지 않습니다. 18시까지 남아야 하는 일정이 아니며, 로댕 때문에 축제를 무리하게 줄이지 않습니다.
- 생트샤펠 9/13 12:00과 로댕 9/13 16:40은 예약 완료가 아닌 목표입니다. 노트르담 미사는 전체 관광 시간과 구분합니다.
- 9/17 루브르·들라크루아를 넣으면서 기존 달리그르·쿨레 베르트·GGE·식물원과 일요일 Le Florentin은 보류 후보로 남겼습니다. 추가할 때만 일정·예산을 다시 계산합니다.
- 9/18은 큰 짐을 먼저 Pullman에 맡기는 흐름입니다. 사전 보관·체크인 조건은 호텔에 확인합니다.
- 9/12–13 RER B 중앙 구간 공사가 있으므로 CDG→Saint-Michel 직결을 전제로 하지 않습니다. 앱의 RER 금액은 비교 기준이고, 도착일에는 공식 택시를 fallback으로 확인합니다. [RATP 공사 안내](https://www.ratp.fr/decouvrir/coulisses/modernisation-du-reseau/rer-b-travaux)

## 2인 예산

유로는 2인 계획 예산이며, 항공·숙박·도시세·개인 쇼핑은 제외합니다. 예산의 원본은 [`index.html#daily-budget-data`](index.html#daily-budget-data)입니다. 메뉴·운임·잔여석이 확인되지 않은 값은 추정입니다.

### 기본 시나리오 — 금요일 로댕 fallback

`rodin_plan: "friday"`와 선택 쇼핑 미포함 기준입니다. 로댕을 일요일에 방문하지 못하면 금요일 €28/2인을 사용합니다.

| 날짜 | 2인 유로 예산 |
|---|---:|
| 9/12 토 | €110.00 |
| 9/13 일 | €168.20 + **₩27,052 기결제** |
| 9/14 월 | €197.10 |
| 9/15 화 | €206.30 |
| 9/16 수 | €283.20 |
| 9/17 목 | €211.10 |
| 9/18 금 | €209.30 |
| 9/19 토 | €154.20 |
| **합계** | **€1,539.40 + ₩27,052** |
| 첫날 택시 선택 시 | **€1,576.40 + ₩27,052** |

### 일요일에 로댕을 본 경우

일요일 예산에 로댕 €28을 더하고 금요일 로댕을 빼는 시나리오입니다. 금요일에는 몽소 14:00–15:10과 Pleincœur 15:30–16:00을 선택 후보로 둡니다.

- 일요일: **€196.20 + ₩27,052**
- 금요일: **€201.30** (몽소·Pleincœur 포함)
- 전체: **€1,559.40 + ₩27,052**
- 첫날 택시 선택 시: **€1,596.40 + ₩27,052**
- Pleincœur를 선택하지 않으면 전체 유로 합계는 **€1,539.40**입니다.

로댕의 두 날짜를 동시에 예약·결제하거나 €28을 두 번 더하지 않습니다. 유로와 원화는 임의 환율로 합치지 않습니다.

### 예산 원장 계약

- `index.html`의 `script#daily-budget-data`가 유일한 공개 원장입니다.
- `cents`와 `range`는 이미 **2인 기준 EUR 센트 정수**입니다. 다시 2배 하지 않습니다.
- `rodin_plan`은 `friday`(기본) 또는 `sunday`이며, `rodin_day`가 붙은 로댕 항목 중 하나만 활성화합니다.
- `optional`·`included`는 체크박스 선택 상태를 나타냅니다. `paid_currency`, `paid_amount`, `purchase_source`는 유로 원장과 별도로 실결제를 보존합니다.
- `status: verified`는 공식 단가 확인이지 예약·구매 완료가 아닙니다. `excluded`의 €0도 무료라는 뜻이 아닙니다.
- 장소 카드의 `place`, 지도 경로의 `data-src`, 원장 항목을 바꿀 때는 이름·순서·앞뒤 구간을 함께 확인합니다.

### 검증

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
node --check tests/browser_smoke.cjs
node <<'JS'
const fs = require('node:fs');
const vm = require('node:vm');
const html = fs.readFileSync('index.html', 'utf8');
for (const [, attrs, body] of html.matchAll(/<script([^>]*)>([\s\S]*?)<\/script>/g)) {
  if (attrs.includes('application/json')) JSON.parse(body);
  else new vm.Script(body);
}
console.log('Inline JavaScript and JSON: OK');
JS
git diff --check
```
